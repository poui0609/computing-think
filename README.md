# 이그잼 플래너 (Exam Planner)

학생용 통합 일정 관리 앱. 수업·과제·시험 일정을 한 곳에서 관리하고, 앱을 켜면 가장 급한 일정을 자동으로 상단에 표시합니다. (컴퓨팅사고 프로젝트 기획서 기반)

## 기능

- 일정 입력 / 저장 / 조회 (CSV 파일로 저장)
- D-day 계산 + 임박순 정렬 (가장 급한 일정이 맨 위)
- 월간 캘린더 뷰
- 일정 수정 / 삭제 / 완료 체크
- 종류 구분: 수업 🟦 · 과제 🟧 · 시험 🟥 · 기타 ⬜

## 실행 방법

1. (최초 1회) 필요한 라이브러리 설치

   ```
   pip install -r requirements.txt
   ```

2. 앱 실행

   ```
   streamlit run app.py
   ```

   실행하면 브라우저가 자동으로 열립니다. 열리지 않으면 터미널에 표시되는 주소(보통 http://localhost:8501)로 접속하세요.

## 파일 구성

- `app.py` : 화면(UI) 계층 — Streamlit으로 만든 모든 화면
- `planner.py` : 데이터/로직 계층 — CSV 저장, D-day 계산, 임박순 정렬
- `schedules.csv` : 일정 데이터 (앱 첫 실행 시 자동 생성)
- `requirements.txt` : 필요한 라이브러리 목록

화면과 로직을 두 파일로 나눈 이유는, 로직을 화면 없이 단독으로 테스트할 수 있고 나중에 다른 화면으로 바꿔도 로직을 재사용할 수 있기 때문입니다.

## 컴퓨팅 사고 적용

- 문제 분해: 입력·저장·계산·표시를 별도 함수로 분리
- 패턴 인식: 수업/과제/시험을 같은 일정 구조(Schedule)로 일반화
- 추상화: CSV 입출력을 planner 모듈 함수 뒤로 숨겨 화면은 신경 쓰지 않음
- 알고리즘: D-day 계산 후 남은 일수 기준 오름차순 정렬로 임박순 구현
