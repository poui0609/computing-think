# 이그잼 플래너 (Exam Planner)

연세대학교 학부생을 위한 강의별 일정·과제·시험 관리 웹 앱입니다.  
Streamlit 기반으로 동작하며, 반복 규칙·진행률 추적·캘린더 시각화 기능을 제공합니다.

---

## 실행 방법

### 1. 의존성 설치

```bash
pip install -r requirements.txt
```

### 2. 앱 시작

```bash
streamlit run app.py
```

브라우저에서 `http://localhost:8501` 이 자동으로 열립니다.

---

## 페이지별 사용법

### 홈

- **이번 주 진행률**: 수강 과목별 해당 주차 완료율을 바 형태로 확인합니다.  
  상단의 주차 숫자를 변경하면 다른 주차의 진행률도 조회할 수 있습니다.
- **오늘·임박 일정**: D-0 ~ D-3 이내에 마감되는 일정을 강조 표시합니다.
- **다가오는 일정**: 그 이후 미완료 일정 목록입니다.
- **지난 미완료 일정**: 마감이 지났지만 아직 완료 처리되지 않은 일정입니다.
- 각 카드의 **슬라이더**로 진행률(0~100%)을 조정하고, **완료 체크박스**로 완료 처리할 수 있습니다.  
  완료 체크 시 진행률이 100%로, 완료 해제 시 0%로 초기화됩니다.

---

### 수강 과목

수강 중인 과목을 등록·관리합니다.

1. **학정번호 입력** → 자동으로 교과목명을 조회합니다.  
   (`assets/CourseMapping.json`에 등록된 과목만 자동 조회. 없으면 직접 입력.)
2. **과목 추가** 버튼으로 저장합니다.
3. 등록된 과목 목록에서 **삭제** 버튼으로 제거할 수 있습니다.  
   삭제 시 해당 과목에 연결된 모든 일정과 규칙도 함께 삭제됩니다.
4. 하단 **학기 설정**에서 학기 시작일·종료일을 설정합니다.  
   (주차 계산의 기준이 됩니다. 기본값: 2026년 1학기)

> **CourseMapping.json 업데이트 방법**  
> `utils/course_id_parser.py`를 실행하면 PDF에서 학정번호-교과목명 매핑을 추출해 자동 생성합니다.

### 일정

수동으로 일정을 추가하고 관리합니다. **3가지 도메인**으로 분류됩니다.

#### 일정 추가

오른쪽 상단 **`+ 일정 추가`** 버튼을 누르면 팝업이 열립니다.  
팝업 내에서 **수업 / 학사 / 개인** 탭을 선택해 도메인을 고릅니다.

---

**수업 일정** — Learnus 기반 수업 관련 일정 (학정번호 필수)

| 일정 종류 | 타이밍 | 입력 항목 |
|---------|------|---------|
| 동영상 강의 | 마감형 | 과목, 제목, 시작 시각(선택), 마감일시 |
| 화상강의 | 교시형 | 과목, 제목, 날짜, 시작~종료 교시 |
| 과제 | 마감형 | 과목, 제목, 시작 시각(선택), 마감일시 |
| 조별과제 | 마감형 | 과목, 제목, 시작 시각(선택), 마감일시 |
| 퀴즈 | 교시형 | 과목, 제목, 날짜, 시작~종료 교시 |
| 시험 | 교시형 | 과목, 제목, 날짜, 시작~종료 교시 |

교시 입력 시 내부적으로 실제 시각으로 변환됩니다.  
(1교시 09:00~10:00 / 2교시 10:00~11:00 / ... / 15교시 23:00~00:00)

---

**학사 일정** — 학과·학교 주관 행사 (학정번호 없음)

| 일정 종류 | 타이밍 | 설명 |
|---------|------|-----|
| 세미나 | 구간형 | 특강, 세미나 참여 |
| 전시/박람회 | 구간형 | 전시회, 박람회 참관 |
| 교내 대회 | 마감형 | 교내/학과 주관 대회 (접수 마감 기준) |
| 학사 행사 | 구간형 | 오리엔테이션, 졸업식 등 공식 행사 |

---

**개인 일정** — 본인 학습·생활 일정 (학정번호 없음)

| 일정 종류 | 설명 |
|---------|-----|
| 시험 공부 | 특정 시험을 위한 자습 블록 |
| 퀴즈 대비 | 퀴즈 대비 공부 시간 |
| 자습 | 일반 자습 시간 |
| 동아리 | 동아리 활동 |
| 봉사 | 봉사 활동 |
| 외부 대회 | 코딩 대회 등 교외 대회 참여 |
| 기타 | 자유 입력 |

---

#### 일정 목록

- **필터**: 도메인(수업/학사/개인), 과목, 일정 종류, 표시 범위(미완료/완료/전체)로 필터링합니다.
- 각 일정 카드에서 진행률 슬라이더와 완료 체크박스를 조작합니다.
- **수정** 버튼으로 내용을 편집하고, **삭제** 버튼으로 제거합니다.

---

### 반복 규칙

매주 자동으로 일정을 생성하는 규칙을 관리합니다.

#### 규칙 만들기

1. 상단의 **규칙 추가** 섹션에서 과목·일정 종류를 선택합니다.
2. 제목 템플릿에 `{week}` (주차 번호) 또는 `{label}` (일정 종류명)을 사용할 수 있습니다.  
   예: `{week}주차 과제` -> "1주차 과제", "2주차 과제", ...
3. 규칙 패턴을 선택합니다:
   - **기간형 (window_cycle)**: 매주 특정 요일·교시에 열리고, N주 후 특정 요일·시각에 마감되는 과제/동영상에 적합
   - **교시형 (period_weekly)**: 매주 특정 요일·교시구간에 열리는 화상강의/퀴즈에 적합
   - **마감형 (due_weekly)**: 매주 특정 요일·시각에 마감되는 단순 기한형 일정에 적합
4. **저장 및 일정 생성** 버튼으로 학기 전체 일정을 자동 생성합니다.

#### 규칙 목록

- 연결된 일정 수 표시, **재생성** 버튼으로 미완료 일정을 다시 만듭니다.
- **삭제** 시 규칙과 연결된 모든 일정이 함께 삭제됩니다.

---

### 캘린더

월간 캘린더로 일정을 시각화합니다.

- **이전/다음** 버튼으로 월을 이동하고, **오늘** 버튼으로 현재 월로 돌아갑니다.
- 각 날짜에 일정이 **바(bar)** 형태로 표시됩니다.
  - 단일 날짜 일정: 점과 짧은 바
  - 기간형 일정: 시작일~종료일 형태로 기간을 시각적으로 표현
  - **수업 일정**: 과목 색상 / **학사 일정**: 보라색 / **개인 일정**: 초록색
- 날짜를 클릭하면 상단에 **일정 상세 패널**이 열리고, 진행률·완료 여부를 조작할 수 있습니다.
- **필터**: 과목, 일정 종류, 완료 여부, 주차 progress 표시 여부를 설정합니다.

---

### 데이터 관리

일정 데이터를 백업하고 복원합니다.

#### JSON 내보내기 / 가져오기

- **JSON 내보내기**: 현재 모든 데이터를 `.json` 파일로 다운로드합니다.
- **JSON 가져오기**: 이전에 내보낸 `.json` 파일을 업로드합니다.
  - **덮어쓰기**: 기존 데이터를 모두 지우고 파일의 데이터로 교체합니다.
  - **병합**: 기존 데이터에 파일의 데이터를 추가합니다. (ID 중복 항목은 건너뜁니다.)

#### ICS 내보내기

- 일정 데이터를 `.ics` 형식으로 내보내 Google 캘린더·Apple 캘린더 등 외부 캘린더 앱에서 가져올 수 있습니다.

## 진행률 색상 의미

| 진행률 | 색상 |
|------|------|
| 0 ~ 9% | 빨간색 |
| 10 ~ 29% | 주황색 |
| 30 ~ 49% | 노란색 |
| 50 ~ 69% | 연두색 |
| 70 ~ 89% | 초록색 |
| 90 ~ 99% | 진한 초록 |
| 100% | 청록색 (Clear!) |

## 이벤트 도메인 분류

| 도메인 | 색상 | 학정번호 | 예시 |
|------|------|---------|-----|
| 수업 | 과목 고유색 | 필수 | 시험, 과제, 동영상 강의, 화상강의 |
| 학사 | 보라색 | 없음 | 세미나, 박람회, 교내 대회, 학사 행사 |
| 개인 | 초록색 | 없음 | 시험 공부, 동아리, 봉사, 외부 대회 |
